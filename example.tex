\section*{Counting with state}
Every known name links to its documentation on Hackage, and operators become \enquote{ligatures}
that still copy as the original text:
\begin{minted}{haskell}
import Control.Monad.State

-- count the calls of the step function
counter :: Int -> State Int [Int]
counter n = do
  xs <- mapM (\x -> modify (+1) >> pure (x * 2)) [1 .. n]
  k  <- get
  when (k /= n) $ error "unreachable"
  pure (filter even xs)
\end{minted}
